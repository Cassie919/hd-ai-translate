这是一个基于 Spring Boot 的 AI 翻译系统，主要功能是提供文档翻译服务，支持多会话管理和导出功能。

核心技术栈
基础框架
Spring Boot 3.2.0 - 核心应用框架
Java 21 - 编程语言版本
核心依赖
Spring AI Alibaba (1.0.0.2) - AI能力集成，通过阿里云的 DashScope（通义千问）提供服务
LangChain4J (v1.0.0-beta2) - 提供额外的AI链式调用能力
Spring Data Redis + Redisson - 数据持久化和分布式锁
Apache POI (5.2.5) - 处理Word文档导入/导出
Lombok - 简化实体类开发
数据存储
Redis - 用于会话状态管理和缓存（通过 Redisson 实现）

1.会话
```
上传文件 → 创建会话 → 分配 sessionId → Redis存储
↓
Redis存储结构:
- translate:meta:{sessionId} → 会话元数据（状态、文件名等）
- translate:data:{sessionId} → 翻译结果分段列表
- TTL: 30分钟自动过期
```
2.翻译
```agsl
用户上传文件 → ChapterService 解析 → TranslateService 翻译 → AI接口调用 → 结果存储
                     ↓
               支持多会话并发

```
