1.会话隔离方案
    
    流程：
    1️⃣ 前端生成 sessionId
    每个用户/每次翻译独立一个 session
    刷新页面后可以取回之前的 sessionId
    可以新增“重新开始” → 生成新 sessionId
    2️⃣ 后端用 Redis （redission)存：（本地运行的容器 密码123456）
    对于一个 sessionId，至少有 2个 key：
    translate:meta:{sessionId}   → 存状态（小数据）
    translate:data:{sessionId}   → 存结果（分段List）
    ttl: 30分钟

    接口：每个接口都必须接收 sessionId
    3️⃣ 刷新页面：
    
    还在 → 数据恢复
    超时 → 自动清空
