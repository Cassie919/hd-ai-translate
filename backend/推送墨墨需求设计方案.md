新增推送墨墨模块。有两个步骤，首先推送单词到生词本，然后给单词添加例句。逻辑是这样的：

1、推送单词到生词本：
输入: notepadId, words[]
│
├─ GET 云词本当前内容
│
├─ 查找/创建 "## 2026-06-12" 日期标题
│
├─ 对比去重 → uniqueWords（新增）/ duplicateWords（重复）
│
├─ 将 uniqueWords 插入今日标题下方
│
├─ POST 更新后的云词本内容
│
└─ 返回成功消息（新增了哪些，哪些已存在）



2、给单词添加例句：
输入: word（单词）, sentence（例句）, translation（译文）
│
├─ GET /vocabulary?spelling={word}
│   └─ 获取单词 ID
│
├─ POST /phrases
│   └─ 创建例句，关联单词 ID + 附上标签和来源
│
└─ 返回 "例句已添加到单词 xxx"

3、在墨墨云词本中创建一个新的云词本（Notepad），将单词列表写入其中。具体逻辑如下：

构建请求头：调用 getHeader() 获取认证信息（包含 API Token 等）。


获取当前日期：用 en-CA 格式（YYYY-MM-DD）获取今天的日期，作为 Markdown 内容的标题。


发送 POST 请求：向墨墨 API 的 /notepads 接口发送请求，body 包含：

status: "PUBLISHED" — 直接发布
content — Markdown 格式，以日期为一级标题，每个单词单独一行
title — 固定为 "Novel Translate Skill"
brief — 简介 "小说词汇"
tags — 标签 ["novel"]

处理响应：

如果创建成功（success 为 true 且返回了 notepad），将返回的 notepad.id 保存到本地文件（notepadIdFilePath），用于后续向同一个记事本追加单词。
返回成功提示，告知用户哪些单词已添加。
如果失败，抛出错误。
简单说就是：向墨墨的云词本 API 创建一个新的记事本，把要背的单词写进去，并保存记事本 ID 供后续追加使用。

相关接口：
墨墨开放 API（https://open.maimemo.com/open/api/v1），共涉及 4 个端点、5 次 HTTP 请求：
一、API 汇总表
#	函数	方法	端点	用途
1	createNotepad	POST	/notepads	创建新云词本，批量写入单词
2	addWordsToNotepad	GET	/notepads/{id}	获取已有云词本的完整内容
3	addWordsToNotepad	POST	/notepads/{id}	更新云词本（合并新单词后写回）
4	addSentenceToWord	GET	/vocabulary?spelling={word}	按拼写查单词，获取单词 ID
5	addSentenceToWord	POST	/phrases	为单词创建例句（含翻译）


二、接口详情
1.createNotepad(words) —— 创建云词本

POST /notepads
Header: Authorization: Bearer {token}
Body: {
notepad: {
status: "PUBLISHED",
content: "# 2026-06-13\nword1\nword2\n",
title: "Bob Plugin",
brief: "Bob 插件录入词汇",
tags: ["词典"]
}
}
→ 成功后缓存 notepadId 到本地文件

2、addWordsToNotepad(notepadId, words) —— 向已有云词本追加单词

① GET /notepads/{notepadId}          ← 拉取当前云词本内容
→ 按日期查找 `# 2026-06-13` 标题行
→ 去重：过滤已存在的单词
→ 将新单词插入到当日标题下方

② POST /notepads/{notepadId}         ← 将合并后的内容写回
Body: { notepad: { status, content, title, brief, tags } }

3、addSentenceToWord(word, sentence, translation)

① GET /vocabulary?spelling={word}    ← 查单词，获取 voc_id
→ 如果查不到 → throw "未找到单词"

② POST /phrases                      ← 创建例句
Body: {
phrase: {
voc_id: wordId,
phrase: sentence,
interpretation: translation,
tags: ["词典"],
origin: "Bob Plugin"
}
}
