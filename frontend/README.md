# HD AI Translate（前端）

基于 AI 的英文阅读与翻译学习工具。上传中文小说 txt，按章节进行 AI 翻译，再从译文中挑选生词，一键推送到墨墨背单词云词本。

前端基于 **Vue 3 + Vite + Element Plus + Axios**，共包含两个可用模块：

| 模块 | 路由 | 说明 |
| --- | --- | --- |
| **Chat 对话** | `/chat` | 与 AI 进行多轮对话，支持历史会话管理 |
| **Workflow 工作流** | `/workflow` | 文档 → 翻译 → 意群 → 单词 → 墨墨 的五步翻译学习流程 |

> 首页（`/`）为功能入口选择页，当前对外暴露 Chat 与 Workflow 两个入口。

---

## 一、Chat 对话模块

### 功能说明

- 多轮对话：每次对话携带 `chatId`，AI 会保留上下文记忆。
- 历史会话：左侧栏展示全部会话，标题取该会话的第一条用户消息。
- 新建会话：随时开启一个全新的对话。
- 回复以 Markdown 渲染（标题、列表、代码块、引用、链接等）。

### 使用步骤

1. 在首页点击 **Chat 对话** 卡片，进入对话页。
2. 首次进入若没有历史会话，系统会自动创建一个新会话。
3. 在底部输入框输入消息：
   - 按 `Enter` 发送；
   - 按 `Shift + Enter` 换行。
4. 发送后等待 AI 回复（回复期间输入框与发送按钮为禁用状态）。
5. 切换会话：点击左侧会话列表中的任意条目，即可加载该会话的历史记录。
6. 新建会话：点击左上角 **＋ 新建会话**，开启一段全新对话。
7. 页面 URL 会同步当前会话（`/chat?chatId=xxx`），刷新后可恢复到同一会话。

### 相关接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/chat/create` | POST | 创建会话，返回 `chatId` |
| `/api/chat/do-chat` | POST | 发起对话（`message` + `chatId`），返回 AI 回复 |
| `/api/chat/history` | GET | 查询指定会话的历史消息 |
| `/api/chat/list` | GET | 查询全部会话 ID 列表 |

## 二、Workflow 工作流模块

### 功能说明

工作流是一条从"上传文档"到"生词推送"的完整链路，共五个步骤：

```
文档 → 翻译 → 意群 → 单词 → 墨墨
```

- **文档**：上传 txt、解析章节、查看章节原文。
- **翻译**：整章 AI 翻译，逐段展示英文与中文对照。
- **意群**：对翻译结果做意群切分，用 `|` 分隔，帮助理解长句结构。
- **单词**：在译文中点击英文单词标记生词，自动做词性还原，并匹配例句与译文。
- **墨墨**：将标记的生词（按原型去重）推送到墨墨背单词云词本，可选是否附带例句。

### 使用步骤

#### 步骤 0：上传文档

1. 在首页点击 **Workflow** 卡片进入工作流页。
2. 点击左上角 **选择文档**，在弹窗中选择一个 `.txt` 文件（支持 UTF-8 编码）。
3. 点击 **确定**，后端解析文件并返回 `sessionId` 与章节列表。
4. 上传成功后，左侧显示当前文档名与章节列表。

#### 步骤 1：文档

5. 在左侧章节列表中点击某一章节，右侧即可查看该章节的原文内容。

#### 步骤 2：翻译

6. 点击顶部步骤条中的 **翻译**，系统对当前章节调用 AI 进行翻译。
7. 翻译完成后，按段落逐条展示：上方为**英文**，下方为**中文**。
8. 若已翻译过，会直接复用已有结果，不重复请求。

#### 步骤 3：意群

9. 翻译完成后会**自动异步发起意群划分**，你也可以点击步骤条中的 **意群** 查看结果。
10. 每条译文按意群切分，意群之间以 `|` 分隔，便于对照理解句子结构。

#### 步骤 4：单词

11. 点击步骤条中的 **单词**。
12. 在「翻译」或「意群」面板中**点击任意英文单词**即可标记为生词（再次点击取消标记）。
13. 已标记的生词会自动进行**词性还原**（例如 `ran → run`），并在本步骤按字母顺序汇总展示。
14. 面板下方展示每个生词在译文中的**例句与例句译文**，未匹配到例句的单词会单独列出。
15. 点击生词 chip 右侧的 `×` 可取消该标记，点击 **清空** 可一键清除全部生词。

#### 步骤 5：墨墨

16. 点击右上角 **配置**，填入墨墨 API Token 并保存（后端会先校验有效性，无效不会保存）。
    - 获取方式：墨墨背单词 App → 我的 → 更多设置 → 实验功能 → 开放 API。
17. 点击步骤条中的 **墨墨**，查看将要推送的生词列表。
18. 选择推送方式：
    - **仅推送单词**：只把生词追加到云词本（后端自动去重）。
    - **推送单词和例句**：生词 + 对应例句一并推送；未匹配到例句的单词会被忽略。
19. 推送完成后，面板内会展示结果：新增单词、已存在单词、例句成功/失败数量。

### 状态缓存与恢复

- 文档名、章节列表、当前章节、翻译结果、意群结果、当前步骤会缓存到 `sessionStorage`（key：`translate_workflow_state`）。
  - **同一标签页内刷新**可自动恢复；关闭标签页后缓存清空，新开标签页会从零开始，也不再受多标签页互相覆盖的影响。
- `sessionId` 仍保存在 `localStorage`（见 `src/utils/session.js`），用于跨标签页续接同一个后端会话。
- 若后端会话已失效，会提示重新上传文档。
- 已标记的生词不持久化，刷新后清空。

### 相关接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/upload` | POST | 上传 txt，返回 `sessionId` 与章节列表 |
| `/api/session/{sessionId}` | GET | 校验会话是否有效 |
| `/api/chapter/content` | GET | 获取指定章节原文 |
| `/api/translate` | POST | 翻译指定章节，返回逐段结果 |
| `/api/phrase-chunk` | POST | 对翻译结果做意群划分 |
| `/api/word/examples` | POST | 为生词匹配例句与译文 |
| `/api/word/lemmatize` | POST | 批量词性还原（返回原型） |
| `/api/maiMemo/set-token` | POST | 设置墨墨 Token（会先探活校验） |
| `/api/maiMemo/token-status` | GET | 查询是否已配置墨墨 Token |
| `/api/maiMemo/add-words` | POST | 仅推送单词 |
| `/api/maiMemo/push` | POST | 推送单词和例句 |
| `/api/user/info` | GET | 获取当前用户信息 |

## 三、本地启动

### 环境要求

- Node.js 18+
- npm

### 启动步骤

```bash
npm install
npm run dev
```

启动后访问：<http://localhost:3001>

> 开发环境下 `/api` 请求由 Vite 代理到后端 `http://localhost:8124`（见 `vite.config.js`），请确保后端服务已启动。

### 构建

```bash
npm run build      # 产物输出到 dist/
npm run preview    # 本地预览构建产物
```

### Docker

```bash
docker build -t ai-translate-frontend:latest .
docker run -d -p 3001:80 --name ai-translate-frontend ai-translate-frontend:latest
```
